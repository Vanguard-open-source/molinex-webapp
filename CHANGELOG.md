# Changelog

All notable changes to Molinex are documented in this file.

## [0.1.0] - 2026-10-04

### Added

- Responsive application shell and bounded-context navigation.
- English and Spanish internationalization support.
- Operational overview for production activities.
- Raw material reception and lot management.
- Production batch and production record management.
- Quality result and production waste registration.
- Machinery inventory management.
- Preventive and corrective maintenance workflows.
- JSON Server mock API with integrated Sprint 2 data.

### Changed

- Aligned the frontend structure with Domain-Driven Design and Clean Architecture.
- Improved production, quality, waste, machinery, and maintenance views.
